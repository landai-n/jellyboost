These chips are local UserEntity rows — accounts that signed in on THIS device — not the server’s live public-users list, so the layout is deliberately different from Login’s 88px avatar-ring row: compact 60px pills, metadata line, badges. Sam holds a valid token: one tap connects and lands on Home. Alex’s token expired: the error badge marks it; tap opens Login with the username prefilled (Quick Connect still offered). Long-press a chip for the remove state (components/account-chip.html). “Sign in as someone else” opens the normal Login screen, whose “Who is watching?” row remains the live public list.
