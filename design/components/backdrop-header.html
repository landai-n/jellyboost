BackdropHeader.kt itself only draws full-bleed artwork + JellyfinGradients.BackdropScrim (transparent → background@65% → #101010, bottom-left) and, when passed, a plain optional title/subtitle pair — no eyebrow, no star rating, no cert badge by default. The richer lockup shown here — eyebrow, 34px/700/-.02em title, then a ★ rating / year / outlined TV-MA pill / season count meta row — is what the detail screen's own DetailHero (ItemDetailHeader.kt's TitleLockup) layers on top of the generic header. Included at full richness here so the card is a useful reference for how the component is actually used, not just what it draws unassisted.
