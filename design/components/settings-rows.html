Row anatomy
Six row types, and nothing else. A new setting picks one of these — if it fits none, that is the signal to talk about it rather than to invent a seventh. Every type is a single touch target at 48dp minimum, and the control it contains is inert: the row owns the click and the semantics, which is what gives TalkBack the role and state.

Danger row
Sign out
Error tint, last in its panel, always confirmed. The sign-out dialog keeps its unchecked “Also delete downloads from this device” box, and the button holds a spinner while the server goodbye is in flight.
Metrics, all lifted from Dimens and unchanged by this redesign: header gutter 20dp (HeaderPadding), content gutter 16dp (ScreenPadding), panel radius 16dp (PanelRadius), section gap 24dp, hairline separators between rows inside a panel and none between panels, content capped at 640dp so a label never sits at one edge with its switch at the other. The one thing that changes: section headings become the design system’s 11/W600/.14em eyebrow instead of the 17sp primary SectionTitle — they still carry heading() semantics, which is how TalkBack jumps between them. Two rules on top: an eyebrow only earns its place on a page carrying more than one section (on a single-section page the screen title already does that work, and Appearance and Network draw none), and a category is called the same thing on its hub row and on its own page — no long-form alias waiting inside.
